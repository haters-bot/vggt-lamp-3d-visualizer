# PairUAV预测结果可视化工具

完整说明见 [仓库 README](../README.md)。

```bash
python kml_spiral_editor.py --no-browser
```

打开 <http://127.0.0.1:7872/>：

1. 程序启动后自动加载内置 `building_1565` 50 图模型；侧栏以真实航拍缩略图展示三个模型，点击卡片即可切换，无需文件管理器。模型、50 张实拍图和预测缓存会同步切换。相机锥体必须按输入顺序，顶点 1 为光心。
2. 默认使用暖白期刊风界面和画布；也可在“显示”切换深色、黑色或纯白背景，并调整点预算、点大小及 EDL。网格、坐标轴和检测底面默认隐藏。
3. 选择内置模型后自动切换对应的实拍图和 `prediction_caches/` 缓存；随后可在主视图底部时间轴点击两次选择起点和终点，再点击侧栏“预测目标位置”按钮读取缓存并显示赭金色预测点。悬停时间轴可预览当前模型图片，侧栏图片下拉框仍可作为备用输入。
4. 预测位置仅使用带方向的 range 序列步差。普通视锥在轨迹上带低调光心点，三只高亮视锥带同色高亮锚点和两条辅助连线；点击任一高亮视锥附近会吸附并切换到对应航拍视角。
5. 预测后自动打开朝向建筑中心的预测视角预览；也可单击渐细轨迹的任意位置打开同样朝向中心的预览，选择分辨率并保存 PNG。主视图和导出背景一致。
6. 轨迹使用 University-1652/PairUAV 的固定 45°、4°/0.5 m 规则螺旋，并通过鲁棒 Sim(3) 对齐 VGGT 相机光心、降低异常光心权重；随后按图片输入顺序从较深较粗渐变到较浅较细。网格 GLB 的模型与相机有独立图层开关，点云 GLB 可用圆形 splat 开关比较方点。
7. 手机竖屏自动切换为紧凑控制区和主视图，横屏和平板使用窄侧栏；单指旋转，双指开合缩放，双指拖动平移。底部时间轴具有更大的触控热区并避开系统安全区。
8. 页面右上角可在中文与英文界面之间切换；语言和当前建筑模型会在浏览器中记忆。

`vendor/` 沿用 Three.js r160；本分支不增加 CDN/npm 依赖。`rendering.js` 是本地 splat/EDL 实现，`orbit_math.js` 是本地轨道几何及缓存校验。服务启动时载入 HTML，修改后重启服务。

固定模型、图片和缓存均从交付目录读取；界面不提供外部文件导入入口，以避免跨建筑资源误配。
