# 本地三维界面

完整说明见 [仓库 README](../README.md)。

```bash
python kml_spiral_editor.py --no-browser
```

打开 <http://127.0.0.1:7872/>：

1. 加载固定模型库中的 GLB；页面按文件内容指纹自动切换到对应的 8/50 张实拍图。相机锥体必须按输入顺序，顶点 1 为光心。
2. 默认使用暖白期刊风界面和画布；也可在“显示”切换深色、黑色或纯白背景，并调整点预算、点大小及 EDL。网格、坐标轴和检测底面默认隐藏。
3. 加载 `lamp_cache.json` 后可在主视图底部时间轴点击两次选择起点和终点，第二次点击会自动预测并显示橙色预测点；悬停时间轴可预览图片。侧栏下拉框仍可作为备用输入。
4. 检查三只高亮视锥和两条辅助连线；点击任一高亮视锥附近会吸附并切换到对应航拍视角。普通相机视锥保持低透明度；默认 angle，range 真实图输出尚未验证。
5. 预测后自动打开预测视角预览；也可单击渐细轨迹的任意位置打开预览，选择分辨率并保存 PNG。主视图和导出背景一致。
6. 无发光的期刊蓝灰轨迹按图片输入顺序从较深较粗渐变到较浅较细；网格 GLB 的模型与相机有独立图层开关，点云 GLB 可用圆形 splat 开关比较方点。

`vendor/` 沿用 Three.js r160；本分支不增加 CDN/npm 依赖。`rendering.js` 是本地 splat/EDL 实现，`orbit_math.js` 是本地轨道几何及缓存校验。服务启动时载入 HTML，修改后重启服务。

传入 `--image-dir /path/to/images` 可关闭内置多图片集模式并使用一个自定义目录。远端 LaMP 服务也必须以当前图片集目录启动；新版服务会拒绝图片集名称不一致的请求，防止跨建筑误推理。
